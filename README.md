This is a modern E-Commerce mobile application built using Flutter, designed to provide a smooth and user-friendly online shopping experience. The app allows users to browse products, search items (including voice search), manage their cart, and complete the checkout process with ease.

The project focuses on clean UI design, responsive layouts, and scalable architecture to ensure better performance and maintainability. It also includes features like invoice generation and order management to simulate a real-world e-commerce system.

This project was developed as a learning-based implementation, and the development knowledge and techniques were learned from Unknown Pro Flutter resources, along with hands-on practice and experimentation.
